## هسته Xray

در **GitHub Actions** فایل `libv2ray.aar` به‌صورت خودکار از ریلیز رسمی دانلود و داخل APK قرار می‌گیرد.

بیلد محلی:

```bash
bash scripts/download-libv2ray.sh
gradle :app:assembleDebug
```
